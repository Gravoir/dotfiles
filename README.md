# Dotfiles 🛠️

My development environment configuration.

## What's Included

| File | Description |
|------|-------------|
| `.zshrc` | Zsh config with aliases and prompt |
| `.vimrc` | Vim configuration |
| `.tmux.conf` | Tmux keybindings and theme |
| `.gitconfig` | Git aliases and defaults |

## Install

```bash
git clone https://github.com/Gravoir/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

## Zsh Aliases I Can't Live Without

```bash
# Navigation
..      # cd ..
...     # cd ../..
ll      # ls -la
proj    # cd ~/projects

# Git
gs      # git status
gc      # git commit
gp      # git push
gl      # git log --oneline

# Docker
dps     # docker ps
dlogs   # docker logs -f

# Quick edits
vz      # vim ~/.zshrc
sz      # source ~/.zshrc
```
